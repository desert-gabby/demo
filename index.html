Aurora is a placeholder product page built to show a clean, modern single-page layout — hero, features, process, and contact — all in one lightweight static site.

Get started See features

Why teams pick Aurora

Three reasons this demo page exists.

⚡

Fast by default

No frameworks, no build step — just HTML, CSS, and a touch of JavaScript. Loads instantly.

🎨

Looks intentional

A restrained color system and type scale so the page feels designed, not defaulted.

🌓

Light & dark

Toggle the theme in the top right — every color adapts, including the gradient glow.

How it works

  1. 1

    Clone the repo

    Grab the source from GitHub and open index.html in a browser — no install required.

  2. 2

    Customize it

    Swap the copy, colors, and sections in styles.css and index.html to fit your project.

  3. 3

    Ship it

    Push to GitHub Pages, Netlify, or Vercel and it's live in minutes.
